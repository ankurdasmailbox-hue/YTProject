   - Episode Catalog: Displays all 100 episodes from content_map.csv categorized by
     Era (Hadean, Archean, Proterozoic, Paleozoic, Mesozoic, Cenozoic).
   - Status Badges: [Ready to Generate], [Rendering...], [Gate B Review Ready], [Published].

   - Gate B Review Suite:
     * High-definition HTML5 video player for Master MP4 (1080p @ 30fps).
     * Mobile phone mockup player for 9:16 vertical Shorts.
     * Thumbnail Candidate Selector (Click to choose thumbnail A, B, or C).
     * SEO Metadata Editor (Title, Description, Tags, Category).
   - 1-Click Publishing Hub:
     * [Publish to YouTube] (Public/Unlisted, Auto-attaches soft SRT subtitles).
     * [Publish to Facebook] (Page Video post + Facebook Reel).
     * [Publish to Instagram] (Instagram Reel via Meta Graph API).

B. Back-End Server (FastAPI / Python 3.14):
   - /api/episodes: Returns JSON of all episodes with current render/publish status.
   - /api/generate/{id}: Triggers autonomous background pipeline.
   - /api/stream/{id}: Server-Sent Events (SSE) streaming live logs to browser.
   - /api/review/{id}: Serves Gate B payload (MP4, SRT, Thumbnails, JSON metadata).
   - /api/publish/{platform}/{id}: Triggers platform publisher with runtime quota tracking.

4. META (FACEBOOK & INSTAGRAM) API SETUP GUIDE
================================================================================

To enable 1-click publishing to Facebook and Instagram from the Web Studio:

1. Facebook Page:
   - Create a Facebook Page dedicated to "History of Earth".
2. Instagram Professional Account:
   - Create or switch your Instagram account to a "Professional / Creator Account".
   - Link the Instagram account to your Facebook Page in Instagram Settings > Linked Accounts.
3. Meta for Developers App:
   - Go to https://developers.facebook.com and create a new App (Type: "Business").
   - Add Products: "Facebook Login for Business" and "Instagram Graph API".
   - Permissions needed:
     * pages_show_list
     * pages_read_engagement
     * pages_manage_posts
     * instagram_basic
     * instagram_content_publish
4. Tokens Needed (We will configure these in your .env file):
   - META_APP_ID=
   - META_APP_SECRET=
   - FB_PAGE_ID=
   - FB_PAGE_ACCESS_TOKEN= (Never-expiring long-lived page token)
   - IG_USER_ID= (Connected Instagram Business Account ID)
